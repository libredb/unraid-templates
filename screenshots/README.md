# Screenshots

Product screenshots of LibreDB Studio, used in app store submissions.

Captured from a real running container (`libredb/libredb-studio:0.14.1`) against the sample
database that ships with the image. Nothing here is a mockup.

Size is 2160x1350, which is what app stores such as Umbrel ask for.

| File | Shows |
|---|---|
| 01-libredb-studio.png | Query editor with results, connection list and schema tree |
| 02-libredb-studio.png | Chart view built from the same result set |
| 03-libredb-studio.png | Table columns and types alongside query output |
| 04-libredb-studio.png | Admin dashboard with connection health and metrics |

The app icon is in `../icons/libredb-studio.png` (256x256).
